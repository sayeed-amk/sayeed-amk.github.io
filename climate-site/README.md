# Brisbane Climate Change Awareness Website

This is a static website designed to raise awareness about climate change impacts in Brisbane, focusing on the interaction between greenhouse gas emissions, increasing heatwaves, and their impact on wildlife.

## Project Overview

The website is designed for the Brisbane City Council to improve public understanding of climate change and its effects on local wildlife. It provides useful information for Brisbane residents and encourages sustainable practices to reduce emissions and protect local nature.

## Website Structure

The website consists of the following pages:

1. **Home Page (index.html)**: Landing page with hero section and quick highlights
2. **Heatwaves Page (heatwaves.html)**: Information about increasing heatwaves in Brisbane
3. **Wildlife Disruption Page (wildlife.html)**: How heatwaves affect local wildlife
4. **Greenhouse Gas Emission Page (emissions.html)**: Understanding emissions and how to reduce them
5. **About Page (about.html)**: Information about the website's purpose and team
6. **Contact Page (contact.html)**: Contact form and location information
7. **Search Page (search.html)**: Simple search interface
8. **Additional Content Pages**:
   - Heatwaves More Info (heatwaves-more.html)
   - Wildlife Facts (wildlife-facts.html)
